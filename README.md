# 🧮Calculadora

Uma calculadora simples para realizar operações matemáticas básicas de forma rápida e prática.

## Funcionalidades

- Adição
- Subtração
- Multiplicação
- Divisão
- Exibição dos resultados

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript

## Desenvolvimento

Projeto desenvolvido individualmente, com orientação e apoio do professor.
